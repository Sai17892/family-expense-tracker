Connect the shared tracker

This shared version stores your family data in your own Supabase project, so you and your spouse can use the same tracker from different devices.

One-time setup: create a free Supabase project, run the supplied SQL file, then paste the Project URL and anon/public key below. Never paste a service-role key.
Tip: for the simplest private family setup, in Supabase Auth settings you can disable email confirmation. If you keep confirmation enabled, host this HTML on a static HTTPS site and set that URL as an allowed redirect URL.
